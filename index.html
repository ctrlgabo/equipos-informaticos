Presentación

Objetivo estadístico: analizar si el mantenimiento preventivo se asocia con un mejor rendimiento (menos fallas y arranque más rápido) en equipos informáticos, y practicar distribuciones de frecuencia, estadística descriptiva, chi-cuadrado, correlación de Pearson y regresión lineal simple.

Nota: los datos son sintéticos y con fines educativos. Se simulan con un modelo aleatorio; no son mediciones reales.

Contenido de la aplicación

Cuestionario11 preguntas con su variable, tipo y codificación. Base de datosTabla ordenable y filtrable, nueva muestra, CSV e impresión. FrecuenciasTablas de frecuencias, barras, circular, histograma y polígono. DescriptivaTendencia central y dispersión de las variables. Pruebas estadísticasChi-cuadrado, correlación de Pearson y regresión lineal. GráficosDispersión, recta de regresión y comparaciones. ConclusionesResumen de resultados y aspectos para redactar limitaciones.

Cómo usar la aplicación

  1. Revise el cuestionario para conocer las variables.
  2. Explore la base de datos y recorra las secciones en orden con el menú o los botones de navegación.
  3. En las pruebas y los gráficos puede elegir las variables con los menús desplegables.
  4. Para obtener cifras reproducibles (por ejemplo, las de un informe), use en Base de datos el botón Restaurar muestra original. Cada vez que se genera una nueva muestra, todos los resultados cambian.

La muestra activa y las variables elegidas se recuerdan entre páginas mientras use el mismo navegador.
